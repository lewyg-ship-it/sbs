This is your updates feed. Every Markdown file in `src/content/updates/` becomes a post here, newest first.

To add a new update:

1. Create a new file in `src/content/updates/`, e.g. `2026-09-01-tournament-signup.md`.
2. Add frontmatter with `title`, `date`, and an optional `summary`.
3. Write the post body in Markdown below the frontmatter.
4. Commit and push — your host will build and deploy automatically.
